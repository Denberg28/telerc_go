# TeleRC Go v1.0.0 ecosystem baseline — prerelease

This release identifies the aligned v1.0.0 ecosystem baseline. The Android
application retains version 1.0.4/code1000 so its updater and upgrade ordering
remain compatible with installed 1.0.3. Firmware wire versions remain independent.
It is not stable or field-qualified.

Publication requires successful application tests, debug/release lint, all
three actual board firmware builds, and a signed APK whose application ID and
signer match the prior production Go APK. A debug/candidate APK is not a release
upgrade and must never replace the production artifact.

The prior candidate passed 21 JVM tests, lint, host regressions and three actual
firmware builds. This release workflow reruns its required gates from the exact
published source commit. It will not publish if runners/signing/builds fail.

Manual drive acquisition requires neutral and fresh authority. Recovery never
auto-arms or enables. Balancer pause/loss stops travel while preserving local
upright balance; explicit DISARM removes motor torque. Follow GO_BALANCER_V1.md.

Legacy Wi-Fi command authentication/replay protection remains incomplete.
Physical takeover, stopping time, electrical/load/stall behavior, accessory OFF,
installed-device upgrade retention and field RF are NOT TESTED. Use only the
documented restricted test envelope; stable qualification remains blocked.
See START_HERE.md, ecosystem-release.json and the compatibility/commissioning
procedures. Preserve NVS, export settings and retain the previous signed release.

Base/Go ArduRover profiles require the matched field bridge and verified physical
CH7/mode intervention. Direct-drive mini/car/balancer firmware profiles are distinct;
do not interchange board wiring or assume they provide an ELRS receiver.
