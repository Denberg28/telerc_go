# TeleRC Go v1.0.0 ecosystem baseline — prerelease

The dedicated Go repository is now public. This v1.0.0 baseline contains
Android application 1.0.4/code1000, retaining version ordering from 1.0.3.
Firmware versions and board profiles remain independent. This is a prerelease,
not a stable or field-qualified release.

## Verified release
- Same production package io.github.denberg28.telerc.go and signing certificate;
  higher Android version code than the prior Go 1.0.3 APK.
- 21 JVM tests, debug/release lint and APK alignment/signature checks passed.
- Host/memory-safety regressions and three actual ESP32 profiles passed.
- Source snapshots, firmware image hashes, checksums, nested-archive sanitation
  and exact producer provenance checked before publication.
- Application and matching firmware source: 36323abbebfa0d02b069b4f23cb502607f65e7c0.

The existing TeleRC signing environment produced the reviewed immutable Go source
and verified the result against the prior Go APK. No signing key was exported or
replaced. Signing run 39911336206 and Go firmware run 39902508641 are independently
verified by publication. Earlier notes about the private repository and unavailable
signing describe the earlier build attempt; this verified producer resolves this release.

## Installation
Download TeleRC-Go-v1.0.4.apk for the production Go package. This is not the
separately named debug Candidate app. The existing updater intentionally accepts
only stable releases from the legacy Go release location; it does not auto-install
this prerelease. Device installation and settings-retention checks remain NOT TESTED.

Choose the exact firmware board/wiring profile: four-motor MX1508 mini rover,
TT-car jog steering, or SBRB-based balancer. Do not interchange profiles. Preserve
NVS and settings. Base/Go ArduRover operation needs the matched Base field bridge
and verified physical CH7/mode intervention; direct-drive profiles do not imply an ELRS receiver.

## Remaining limits
Legacy Wi-Fi command authentication/replay protection is incomplete. Physical
takeover, stopping time, power/load/stall behavior, auxiliary OFF and field RF
remain unverified. Use the documented restricted commissioning envelope.
Balancer travel-link loss pauses travel while local upright balance can continue;
explicit DISARM removes torque and requires supporting the chassis.
Recovered communication never automatically re-arms or resumes travel authority.

See REALIGNMENT_V1.md, ecosystem-release.json, the firmware installation guide
and the source repository's GO_BALANCER_V1.md. Stable promotion remains blocked
until the documented hardware, security and installation gates are satisfied.
